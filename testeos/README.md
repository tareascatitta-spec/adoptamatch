# Carpeta de pruebas y nuevas ideas

Aquí se dejan los archivos, capturas o borradores de ideas nuevas antes de integrarlas a la página publicada.

## Reglas de la carpeta

- Nada de lo que está aquí se publica. La página real vive en la raíz del proyecto.
- Cada idea nueva puede venir como HTML suelto, captura, texto o un archivo de notas.
- Conviene nombrar los archivos con fecha y tema, por ejemplo:
  - `2026-11-20-idea-nueva-seccion.html`
  - `2026-11-22-captura-diseno.png`
  - `2026-11-25-notas-mejoras.md`
- Cuando una idea se integra a la página, se avisa y el archivo se elimina para no acumular residuos.
